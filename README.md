# Kuller · Demo

Das kleine Einmaleins als Jump’n’Run. Fünf Welten zum Anspielen, ohne Anmeldung, speichert nichts, sendet nichts.

**Spielen:** https://kenaj85.github.io/kuller-demo/

**Trailer (105 s):** https://kenaj85.github.io/kuller-demo/kuller-trailer.mp4

Der Trailer ist aus dem echten Spiel gerendert: Eine Regie führt Kuller durch die Welten, die Musik kommt aus der Klang-Engine des Spiels
(jede Note gerechnet, keine Aufnahme). Ab der Mitte träumt Kuller, was nachts passiert: Antworten wandern in die Datenbank, eine KI baut
die gewünschte Welt, hundert Bot-Kuller prüfen sie, bis einer im Ziel ist, und am Morgen steht die Welt auf der Karte.

Dieses Repository enthält nur die gebaute Seite und den Trailer, keine Quelle.
